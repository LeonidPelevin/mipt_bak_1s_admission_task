# xo

Сетевые крестики-нолики на Go. Сервер играет с несколькими клиентами, приглашать на партию может только сервер. С одним клиентом идёт одна партия

Нужен Go 1.24 или новее. Работает на macOS и Linux

## Запуск

Из папки проекта:

```sh
go build -o xo ./cmd/xo
./xo server
```

В другом терминале:

```sh
./xo client -addr 127.0.0.1:8080 -name alice
```

Для второго игрока нужно открыть ещё один терминал и указать другое имя. Можно запустить `./xo client` без параметров — программа запросит адрес и имя

Имена обязательные, уникальные, без пробелов. Регистр учитывается: `alice` и `Alice` — разные игроки

## Как играть

Команды вводятся внутри программы после `>`:

| Где | Команда | Что делает |
| --- | --- | --- |
| Сервер | `players` | игроки и статистика |
| Сервер | `invite alice server` | пригласить alice, сервер ходит первым |
| Клиент | `accept` или `decline` | ответить на приглашение |
| Сервер | `move alice 1` | сходить в клетку 1 |
| Клиент | `move 5` | сходить в клетку 5, когда придёт очередь |
| Сервер | `games` | незаконченные партии |
| Сервер | `board alice` | поле текущей партии |
| Сервер | `history alice` | все партии с alice |
| Клиент | `history` | поле и история ходов |

В приглашении `client` вместо `server` отдаёт первый ход клиенту. Начинающий играет X. Клетки 1–9 идут слева направо, сверху вниз. Поле обновляется после каждого хода

Остальные команды — `help`, выход — `quit`. На сервере нужно указывать полное имя игрока. На клиенте ID единственной партии или приглашения можно опустить

## Данные и проверка

База сервера — `xo.db`, сессия клиента — `.xo-<hash>.json`. Они сохраняются после перезапуска. Для возвращения под занятым именем нужен прежний файл сессии. Одновременно открыть одну сессию в двух клиентах нельзя

После серверного хода нужно дождаться сообщения «Ход доставлен». Клиент переподключается автоматически; после обнаружения отключения есть 60 секунд на возвращение, потом техническое поражение. Приглашение тоже действует 60 секунд

```sh
go test -race -coverpkg=./... -coverprofile=coverage.out ./...
go tool cover -func=coverage.out
go vet ./...
```
